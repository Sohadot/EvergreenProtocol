Self-Applied Reference Cases

These cases demonstrate how Evergreen Protocol principles have been applied within Sohadot-governed digital assets to preserve reference integrity, version discipline, citation stability, public change memory, and continuity boundaries.

Purpose

Self-applied reference cases make the protocol more legible by showing it in use. Each case covers a specific continuity problem encountered in a governed digital asset, the protocol principles that were applied, and the governance boundaries that were preserved throughout.

These cases come from within the Sohadot asset portfolio. They are not external assessments. They are not third-party evaluations. They document governed continuity practice applied to assets under direct Sohadot control, where the governance logic can be described and shared as a reference.

What these cases demonstrate

Each case demonstrates one or more of the following continuity principles in a concrete asset context:

  • Reference integrity — keeping references within the asset valid, traceable, and citable over time.
  • Version discipline — recording changes explicitly, incrementing versions with intention, and preserving access to prior states.
  • Citation stability — maintaining stable, citable URLs and versioned content so that external references to the asset remain valid.
  • Public change memory — preserving a visible history of changes accessible to readers and systems that consume the asset.
  • Continuity boundaries — declaring what the asset explicitly is not, preventing scope creep, and protecting the reference surface from claim inflation.

Cases

  • Bisulfid — Reference Atlas Continuity — reference surface governance, source discipline, sitemap integrity, and long-horizon terminology stability for a large governed atlas.
  • EuraPlan — Regulatory Reference Continuity — citation stability and update discipline for a multi-country regulatory reference structure under ongoing legislative change.
  • AIElectronicChips — Dependency Reference Continuity — versioned dependency map governance and machine-readable reference structure for compute and component dependencies.
  • Outmerchant — Standard and Diagnostic Continuity — governed measurement boundary, dimension continuity, and public standard preservation for a commerce evaluation surface.

Non-claim statement

Self-applied reference cases do not certify assets, rank systems, approve third parties, or create compliance status. They are documentation of governed continuity practice within assets under Sohadot’s direct control.

No external organization is assessed, rated, scored, endorsed, or evaluated through this layer. No submission mechanism exists. No registry is maintained. No badge or external status is issued as a result of appearing in or being adjacent to these cases.
