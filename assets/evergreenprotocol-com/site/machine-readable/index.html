How to cite these files

For the versioned machine-readable standard reference, cite:

Evergreen Protocol v1.0 (2026). Machine-readable standard reference.
https://evergreenprotocol.com/protocol/v1/standard.json

For specific definitions, include the term and version:

Evergreen Protocol v1.0 (2026). Definition: [term].
https://evergreenprotocol.com/definitions.json

What these files do not provide

  • No certification - these files do not certify any organization, system, or implementation.
  • No compliance verdict - these files do not assess, approve, reject, rank, or score any party.
  • No live API - these are static JSON files, not dynamic endpoints with runtime behavior.
  • No MCP endpoint yet - an MCP-compatible layer remains future-gated and is not open in this architecture.
  • No registry - no organization list, endorsement list, or status list is published.
  • No readiness checklist - no assessment workflow or submission system is opened.

File format

Files use JSON with conservative Schema.org annotations where appropriate. Consumers should treat them as static reference data, not executable API contracts. The authoritative human-readable source remains the public HTML reference pages.

The machine-readable files support reference consumption for the current standard and public application pages. They do not provide a live API, assessment endpoint, registry feed, scoring system, or submission workflow.
