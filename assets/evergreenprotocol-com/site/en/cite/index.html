Citation guidance

How to Cite Evergreen Protocol

For institutional documents, research papers, governance frameworks, and AI-agent-readable reference structures, use the citation formats below. Always cite the version in force at the time of use.

Citing the standard

Plain text

Evergreen Protocol v1.0 (2026). Reference Continuity Standard.
evergreenprotocol.com/en/category-standard/

APA

Evergreen Protocol. (2026). Reference Continuity Standard (Version 1.0).
https://evergreenprotocol.com/en/category-standard/

Chicago

Evergreen Protocol. "Reference Continuity Standard." Version 1.0.
Published June 2026. https://evergreenprotocol.com/en/category-standard/.

BibTeX

@misc{evergreenprotocol2026,
  title   = {Reference Continuity Standard},
  author  = {{Evergreen Protocol}},
  year    = {2026},
  version = {1.0},
  url     = {https://evergreenprotocol.com/en/category-standard/}
}

Citing specific definitions

When citing a specific term from the Definitions page, include the term, the standard version, and the URL:

Evergreen Protocol v1.0 (2026). Definition: [term name].
evergreenprotocol.com/en/definitions/

As definitions are versioned, always include the version in force at the time of use.

Version referencing

Evergreen Protocol uses semantic versioning to make specific states of the standard citable:

  • Major versions (v1.0, v2.0) — material changes to the category definition, scope, or governance structure.
  • Minor versions (v1.1, v1.2) — clarifications or additions that do not change the category boundary or core definitions.
  • Patch notes — typographical or navigational corrections only.

For governance or compliance purposes, always specify the major and minor version. See Changelog for version history.

Usage notice

This standard is published as a public reference. Citation and reference in research, governance documentation, and institutional frameworks is permitted and encouraged, provided the version is accurately stated and the scope boundaries are observed.

This standard does not constitute certification, compliance endorsement, or external audit. See the Category Standard for explicit scope boundaries.
