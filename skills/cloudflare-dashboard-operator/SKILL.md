# Cloudflare dashboard operator

## Purpose

This skill governs how an AI agent may assist with Cloudflare dashboard configuration as an edge security layer only.

Cloudflare is not used as the source of truth, build system, content layer, or primary deployment system.

GitHub remains the canonical operating layer.

The agent may assist with dashboard-guided DNS, TLS, redirects, security posture, caching, and edge protection only under owner supervision.

No API usage is permitted.

## Doctrine

Cloudflare protects. GitHub governs. The repository builds. The asset remains sovereign.

For the binding repository formulation, see `README.md` → **System architecture** → **Cloudflare Edge Security Layer**.
